# V-Sido 標準デザイン

ロボット制御まわりのツール・管理画面の見た目を揃えるための決まりです。
**色の値より先に、下の「3つの原則」を守ってください。** 値だけ真似ても揃いません。

---

## 3つの原則

### 原則1 ── 色は必ずCSS変数（トークン）を経由する

**CSSに色を直接書かない。** `#4169e1` や `rgba(...)` を書いた時点で、
テーマを切り替えても追従しなくなります。

```css
/* ✗ だめ */
.log { color: #9fb4d8; }
.lamp { border: 4px solid #3a4864; }

/* ○ よい */
.log { color: var(--code); }
.lamp { border: 4px solid var(--lamp-off-line); }
```

必要な色にトークンが無ければ、**トークンを増やしてから**使ってください。
実際、ログの文字色・エラーランプ・バーの縁取りなど7箇所が直値のままで、
テーマを変えても変わらない状態になっていたことがあります。

`theme/at_theme.css` が既定値、`theme/themes/*.css` がその上書きです。
色を変えたいときは**これらのファイルだけ**を触れば全画面に効く、という状態を保ってください。

### 原則2 ── 色を決める前に、その色が「どこで使えるか」を測る

**明るい色は、明るい地の上では文字にも細い線にも使えません。**
思い込みで決めず、コントラスト比を計算してから役割を割り当ててください。

| 用途 | 必要なコントラスト比 |
|---|---:|
| 文字 | **4.5** 以上 |
| 線・図形・アイコン | **3.0** 以上 |
| 広い面の地色 | 制約なし（その上に乗る文字が 4.5 を満たせばよい） |

計算は WCAG の相対輝度で行います。各色を 0〜1 に正規化し、
`c <= 0.04045 ? c/12.92 : ((c+0.055)/1.055)^2.4` で線形化して
`L = 0.2126R + 0.7152G + 0.0722B`、比は `(明+0.05)/(暗+0.05)` です。

★**比べる相手は「実際に目に見えている背景」です。** 要素の親をたどって、
透明でない背景色が最初に見つかったところと比べてください。
ピル（`.pill`）のように自前の背景を持つ部品を、その外側の帯の色と比べると
誤判定します（実際に一度これで「基準割れ」と誤検出しました）。

### 原則3 ── 地色を変えたら、その上に乗る文字も一緒に直す

地色だけ変えると、その上の文字が静かに基準を割ります。**必ずセットで直します。**

実際に踏んだ例:

| 変えたもの | 一緒に直したもの | 理由 |
|---|---|---|
| ページ地に青みを入れた | `--mut` を `#4f5c6b` へ濃く | 既定の `#5a6775` だと青地の上で 4.18 |
| 割り当て行の地を濃い黄へ | `--row-marker` を `#3455b8` へ濃く | 主役の青のままだと黄地の上で 4.14 |

## 色の使い方

### ブランドの3色

| 色 | 値 | 役割 |
|---|---|---|
| 青 | `#4169e1` | 主役。ヘッダの帯・ボタン・スライダ・現在値 |
| 黄 | `#ffd700` | 差し色。状態を示す広い面 |
| 赤 | `#d71345` | 異常・危険な操作だけ（Asratec のロゴ色） |

灰 `#a6afb6` 系を罫線・表ヘッダ・図版の本体に使います。

### 配分の目安

ロゴの配色比に寄せます。**白が大半、青が要所、黄と赤はごく少し。**

| | 目安 |
|---|---:|
| 白（地） | 大半 |
| 青 | 8〜10% |
| 灰 | 7% 前後 |
| 黄 | 2% 前後 |
| 赤 | 1% 以下 |

★**青は「多すぎ」に振れやすい**です。ヘッダ全面を青で塗ると簡単に 8% を超えます。
逆に帯をやめると 2% まで落ちて寂しくなります。迷ったら帯を置く側に寄せてください。

### ★ 色ごとの制約（実測値・白地に対するコントラスト比）

| 色 | 白地 | 使えるところ |
|---|---:|---|
| 青 `#4169e1` | **4.85** | 文字にも使える。白文字を乗せる帯にもできる |
| 赤 `#d71345` | **5.16** | 文字に使える |
| 黄 `#ffd700` | **1.40** | ★**白い面では文字にも細い線にも使えない** |

#### 黄色は2段構えにする

黄 `#ffd700` は白地で 1.40 しかないため、**細い線として引くと必ずぼやけます。**
明るい黄は「広い面」と「濃い色の上」にだけ置き、白地の文字・線には暗い側を使います。

| | 値 | 使う場所 |
|---|---|---|
| 明るい黄 | `#ffd700` | 濃い色の上の罫線、広い面（`#ffeda8` などの淡い地） |
| 暗い側の金 | `#7d6600`（文字） / `#8f7500`（線） | 白地の上の文字・グラフの線・枠 |

★以前ヘッダ下に青と黄の細い2本線を引いていましたが、**採用されませんでした**。
黄色を線で使うのは避けてください。

#### 青を帯にするときの上限

`#4169e1` に白文字を乗せると **4.85**。基準 4.5 のすぐ上です。つまり:

- **帯の上ではほぼ白しか文字色に使えない**（`#f7f9ff` で 4.60 が限界）
- **これより明るい青を帯にしてはいけない**
- 帯の中の階層は、色の濃淡ではなく**文字の大きさと太さ**でつける

## 画面の組み方

- **ヘッダは1本の帯**。左端にV-Sidoロゴ、続けてツール名。地色に応じて青版／白版を出し分ける
- **パネル（カード）を並べる**。白い面に罫線1本、角丸。掴んで並び替えられると尚よい
- **本文は白い面に置く**。地色に色を付けるなら、パネルは白のままにして浮かせる
- **危険な操作は赤**（脱力・停止など）。それ以外は青か控えめボタン
- **状態は「面」で示す**（行の地を塗る等）。細い線や小さな点より読み取りやすい

## 使い方

### すぐ始めるとき

`theme/at_theme.css`（既定値）と `theme/themes/brand.css`（ブランド配色）をコピーし、
この順で読み込みます。`reference/` の共通CSS/JSも一緒に使えば、
ヘッダ・パネル・表・バー・ログ・グラフが揃った状態から始められます。

```html
<link rel="stylesheet" href="at_theme.css">
<link rel="stylesheet" href="at_ui.css">
<link rel="stylesheet" href="themes/brand.css">   <!-- 既定値の後に読む -->
```

詳しくは [REFERENCE.md](REFERENCE.md)。

## 迷ったときの判断順

1. その色に**トークンはあるか**。無ければ足す（直値は書かない）
2. その色を**どこに置くか**。文字なら 4.5、線なら 3.0 を満たすか計算する
3. 満たさないなら、**明るい版と暗い版に分ける**（黄色と同じやり方）
4. 地色を変えたなら、**その上の文字も測り直す**
5. 最後に**画面全体での配分**を見る。青が多すぎ／少なすぎになっていないか
